# 🎨 فاتورة — UI/UX Wireframes

**Designer:** gemini-3.1-pro-high (agy) — Codester-inc
**Theme:** Dark (#0a0e1a, #00d9ff cyan, #6c5ce7 purple)
**Fonts:** Cairo / Tajawal — RTL Arabic-first

---

## Design System

```
Colors:
  bg-primary    = #0a0e1a   (خلفية أساسية)
  bg-surface    = #141929   (كروت/أسطح)
  bg-elevated   = #1e2538   (حوار/قوائم)
  accent-cyan   = #00d9ff   (POS button + brand)
  accent-purple = #6c5ce7   (links + highlights)
  text-primary  = #f0f4ff
  text-secondary= #8b95a7
  success       = #00e676
  warning       = #ffb74d
  error         = #ff5252

Typography: Cairo (headings), Tajawal (body)
Spacing: 4/8/12/16/24/32px
Radius: 12px cards, 24px buttons, 999px circular
```

## User Flow: من أول فتح لأول بيع

```
[فتح التطبيق]
     │
     ▼
[Onboarding?] ── لا ──→ [PIN Login]
     │ نعم                    │
     ▼                        ▼
[Step 1: اسم المتجر]    [اختيار الدور]
     │                        │
     ▼                        ▼
[Step 2: عنوان + عملة]  [Home Screen حسب الدور]
     │                        │
     ▼                        ▼
[Step 3: ضريبة + PIN]   [⚡ POS]
     │                        │
     ▼                        ▼
[Home Screen (Owner)]  [مسح barcode / بحث]
     │                        │
     ▼                        ▼
[⚡ POS]                [إضافة للسلة]
                              │
```
